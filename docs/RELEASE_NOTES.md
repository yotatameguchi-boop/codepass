**実験的なリリースです。** 暗号設計の第三者レビューが終わるまで、重要なアカウントには使わないでください。

主な機能:

- ソースコード＋マスターシークレット＋サービス情報から、毎回同じパスワードを作り直す（どこにも保存しない）
- `codepass get <サービス>` で登録済みの設定から呼び出し。`--copy` でクリップボードへ（時間切れで自動消去）
- `--git <タグ>` でコミットの内容を材料にし、ファイルの編集や改行コード変換の影響をなくす
- 打ち間違いに気づける確認コード（3単語）
- 生成仕様v2: `https://www.GitHub.com/login` と `github.com` を同じサービスとして扱う／使える記号の指定（`--symbols`）
- v0.1 で作ったパスワード（仕様v1）はそのまま再生成できる

インストール方法と使い方は [README](https://github.com/yotatameguchi-boop/codepass#readme) を見てください。
各ファイルのハッシュは `SHA256SUMS` にあります。
